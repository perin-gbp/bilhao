# ⏳ 1 Bilhão de Segundos

Um mini-aplicativo feito com **Ionic + Angular** que calcula em tempo real quantos segundos você já viveu e quando completará **1 bilhão de segundos**.  
Desenvolvido com carinho, confetes e uma pitada de matemática existencial 💫

---

## 📱 Instalar no seu dispositivo

### 🍏 iOS / PWA (versão Web)
Acesse o link abaixo ou escaneie o QR Code:

[👉 **Abrir versão Web**](https://perin-gbp.github.io/bilhao/)

![QR Code iOS](https://api.qrserver.com/v1/create-qr-code/?size=220x220&data=https%3A%2F%2Fperin-gbp.github.io%2Fbilhao%2F)

#### 📲 Dica para instalar no iPhone / iPad
1. Abra o link no **Safari**  
2. Toque no botão **Compartilhar → Adicionar à Tela Inicial**  
3. Pronto! O app ficará como um ícone nativo e funcionará offline 🧀

---

### 🤖 Android (APK)
Baixe diretamente o app oficial da release:

[📦 **Download do APK**](https://github.com/perin-gbp/bilhao/releases/latest/download/bilhao.apk)

![QR Code Android](https://api.qrserver.com/v1/create-qr-code/?size=220x220&data=https%3A%2F%2Fgithub.com%2Fperin-gbp%2Fbilhao%2Freleases%2Flatest%2Fdownload%2Fbilhao.apk)

#### ⚙️ Instalação
1. Baixe o arquivo **bilhao.apk** no seu celular  
2. Toque para abrir e **permitir instalação de fontes desconhecidas**  
3. Abra o app e descubra quantos segundos já viveu ⏱️
